# what is going on bro

When I build `jrco_beta/01` on my PC, the French page has a corrupted string at the place of a U+2010 HYPHEN (`‐`).

```text
Ils sont encore… un peu bruts. Je dessine les cartoons pour la moitié de ma vie, mais je n’ai pas été bon en défier moi‐même. Avec un peu de chance, cette BD m’aidera à améliorer mes compétences en dessin. Avec un peu de chance, je peux faire rire les gens. Peut‐être que je peux trouver une copine. J’sais pas. C’est possible.
```

`moi‐même` (UTF-8: `6d 6f 69 e2 80 90 6d c3 aa 6d 65`) becomes `moi ��même` (`6d 6f 69 e2 80 81 81 90 6d c3 aa 6d 65`). `81 81` is added between `80` and `90`, causing the hyphen (`e2 80 90`) to be decoded as U+2001 EM QUAD (`e2 80 81`) followed by two unknown bytes (`81 90`).

This was first introduced and noticed in commit `fc1ee5756cb3480239f49da1ee164c132f011ec0`.

Directly `jq`’ing the string works fine. `jq`’ing to a file works fine. Appending it to a copy-paste of the file up to that point in the generation works fine. I tried putting the script’s temporary file on multiple different filesystems (local ext4, local tmpfs, external Btrfs) and it’s always corrupted. I checked the integrity of all my installed packages. Does the problem come from using the brace group? Even if that’s the case, it obviously shouldn’t be happening.
